# CheckFreq Dense BERT Sweep

This experiment is the high-resolution BERT slice of the CheckWork robustness evaluation. It fixes model, storage tier, and network topology, then densely sweeps checkpoint cadence and per-rank checkpoint size.

## Scope

- Model: BERT-large style transformer, `dp=8`, `pp=1`, `tp=1`.
- Checkpoint cadence: `10, 20, ..., 100` iterations.
- Per-rank checkpoint size: `500, 1000, ..., 5000` MB.
- Modes: `baseline`, `checkfreq_like`, and `sync`.
- Storage/network: `nvme_std` and `network_8_balanced`.

The full run executes one baseline plus 200 checkpointed cells. The quick mode runs a small corner of the grid for smoke testing.

## Running

```bash
source ../../chakra_env/bin/activate
python3 run_robustness.py --quick      # smoke test
python3 run_robustness.py              # full dense sweep
python3 run_robustness.py --skip-gen   # reuse generated traces
python3 run_robustness.py --local      # no ASTRA-sim Docker dependency
python3 plot_results.py
```

## Outputs

- `results/runs.csv` and `results/runs.json` contain one row per simulation.
- `results/summary.csv` contains per-cell CheckFreq-vs-sync comparisons.
- `results/plots/` is generated by `plot_results.py` and ignored by Git.
- `results/timeline_logs/` contains raw simulator output and is ignored by Git.
